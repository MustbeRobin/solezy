01

Setup

Invite Soezy with the required permissions, login through Discord OAuth, choose a server from the dashboard, then enable the modules you want to run.

npm install && npm start
02

Antinuke

Enable anti-nuke, select event protections, choose punishments, and tune thresholds for bans, kicks, channel deletes, and role deletes.

03

Automod

Control anti-spam, anti-link, mention protection, caps filtering, emoji spam limits, and anti-invite handling from one panel.

04

Logging

Route message, moderation, member, invite, voice, admin, role, and channel events to clean logging destinations.

05

Music

Use the music surface to inspect node state, queue, playback, default volume, and premium player controls.

06

Realtime Sync

The dashboard uses Socket.IO. Updates are debounced on the client, written through the bot database helper, then broadcast to every open dashboard tab.
